La cocina. Recibe los pedidos, decide qué hacer y prepara la respuesta.

  • Javael lenguaje en el que se escriben las reglas (por ver)
  • Springbiblioteca de Java ya hecha, para montar el servidor sin partir de cero (por ver)

Datos

Donde se guarda

La base de datos

La despensa. Guarda todo bien ordenado: usuarios, productos, pedidos.

  • MySQLel programa que guarda los datos (por ver)
  • SQLel idioma para pedirle datos: SELECT, INSERT…
  • JDBC / JPAel puente para que Java hable con ella

Aquí no hay pantalla: solo datos.

Con trazo continuo: lo que ya habéis visto en clase. Con trazo discontinuo: lo que falta según el temario.

Y aparte, tus herramientas. VS Code y Eclipse son el cuaderno donde escribes el código. GitHub es donde lo guardas y lo compartes. Maven y JUnit (por ver) sirven para organizar el proyecto Java y comprobar que funciona.

Qué pasa cuando pulsas «Comprar»

  1. Haces clic en un botón que ves en la página (HTML y CSS lo han dibujado).
  2. JavaScript se entera del clic y manda un pedido al servidor (HTTP).
  3. Java recibe el pedido y le pide los datos que necesita a la base de datos (SQL).
  4. MySQL contesta, y Java prepara la respuesta y la devuelve.
  5. JavaScript recibe la respuesta y cambia la página (DOM): «Compra realizada».
