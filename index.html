Qué pasa cuando pulsas «Comprar»

  1. Haces clic en un botón que ves en la página (HTML y CSS lo han dibujado).
  2. JavaScript se entera del clic (evento) y manda un pedido al servidor con fetch (HTTP), con los datos en JSON.
  3. Java recibe el pedido y le pide los datos que necesita a la base de datos (SQL).
  4. MySQL contesta, y Java prepara la respuesta y la devuelve.
  5. JavaScript recibe la respuesta, la convierte a objeto (.json()) y cambia la página (DOM): «Compra realizada».

    Transiciones y anidado

    Animar un cambio (en vez de que ocurra de golpe) y escribir el CSS de un elemento agrupado, sin repetir su nombre.

  }
  a { color: white; }       /* → #menu-hamburguesa a */
